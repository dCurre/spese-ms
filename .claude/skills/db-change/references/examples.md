## 1. Migrazione: nuova tabella + seed (lookup con ID espliciti)

`migrations/add_<entity>.sql`

```sql
-- Crea la tabella <entity> nello schema spese
CREATE TABLE IF NOT EXISTS spese.<entity> (
    id BIGINT PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE
);

-- Seed valori di default (idempotente)
INSERT INTO spese.<entity> (id, name) VALUES
    (1, 'Default'),
    (2, 'Altro')
ON CONFLICT (id) DO NOTHING;
```

## 2. Migrazione: nuova tabella con autoincrement + FK

```sql
CREATE TABLE IF NOT EXISTS spese.<entity> (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    owner_id BIGINT NOT NULL REFERENCES spese.users(id),
    created_at TIMESTAMP NOT NULL DEFAULT now()
);
```

## 3. Migrazione: aggiungere una colonna (idempotente)

```sql
ALTER TABLE spese.expenses

```

## 4. Migrazione: indice di performance

```sql
CREATE INDEX IF NOT EXISTS idx_expenses_list_id
```

## 5. Model SQLAlchemy — `app/database/<entity>.py`

```python
from sqlalchemy import Column, BigInteger, String
from app.database import db


class Entity(db.Model):
    __tablename__ = '<entity>'
    __table_args__ = {'schema': 'spese'}

    id = Column(BigInteger, primary_key=True, autoincrement=True)
    name = Column(String(100), nullable=False, unique=True)
```

Con FK:

```python
from sqlalchemy import Column, BigInteger, String, ForeignKey, DateTime, func
from app.database import db


class Entity(db.Model):
    __tablename__ = '<entity>'
    __table_args__ = {'schema': 'spese'}

    id = Column(BigInteger, primary_key=True, autoincrement=True)
    name = Column(String(255), nullable=False)
    owner_id = Column(BigInteger, ForeignKey('spese.users.id'), nullable=False)
    created_at = Column(DateTime, server_default=func.now())
```

## 7. Route CRUD — `app/api/<entity>/routes.py`

```python
from flask import request, jsonify
from app.api import api
from app.database import db
from app.database.<entity> import Entity


@api.route('/<entities>', methods=['GET'])
def get_entities():
    items = Entity.query.all()
    return jsonify({"<entities>": [{"id": i.id, "name": i.name} for i in items]})


@api.route('/<entities>/<int:item_id>', methods=['GET'])
def get_entity(item_id):
    i = Entity.query.get_or_404(item_id)
    return jsonify({"id": i.id, "name": i.name})


@api.route('/<entities>', methods=['POST'])
def create_entity():
    data = request.get_json() or {}
    i = Entity(name=data['name'])
    db.session.add(i)
    db.session.commit()
    return jsonify({"id": i.id, "message": "Creato"}), 201


@api.route('/<entities>/<int:item_id>', methods=['PUT'])
def update_entity(item_id):
    i = Entity.query.get_or_404(item_id)
    data = request.get_json() or {}
    if 'name' in data:
        i.name = data['name']
    db.session.commit()
    return jsonify({"message": "Aggiornato"}), 200


@api.route('/<entities>/<int:item_id>', methods=['DELETE'])
def delete_entity(item_id):
    i = Entity.query.get_or_404(item_id)
    db.session.delete(i)
    db.session.commit()
    return jsonify({"message": "Eliminato"}), 200
```

Nota: creare anche `app/api/<entity>/__init__.py` (vuoto) come negli altri moduli.

## 9. Schema marshmallow (opzionale) — `app/schemas.py`

```python
from marshmallow import Schema, fields, validate


class EntitySchema(Schema):
    name = fields.String(required=True, validate=validate.Length(min=1, max=100))
```

Uso nella route POST/PUT:

```python
from app.schemas import EntitySchema

data = EntitySchema().load(request.get_json() or {})
```
La `MarshmallowValidationError` e' gia' gestita globalmente in `app/__init__.py` (ritorna 400).
